# Дерево педагогических идей

Участники сканируют один QR-код и отправляют идею. Ответ появляется на экране проектора, в конце показывается общий итог. Вход, почта и пароли не нужны.

## Как запустить

### 1. GitHub
1. Создайте новый **приватный** репозиторий.
2. Нажмите **uploading an existing file**.
3. Перетащите **содержимое** этой папки, чтобы `package.json` оказался в корне.
4. Нажмите **Commit changes**.

### 2. Vercel
1. На [vercel.com](https://vercel.com) нажмите **Add New → Project**.
2. Выберите репозиторий и нажмите **Import**, затем **Deploy**.

### 3. База ответов
База хранит ответы, чтобы они попадали с телефонов на экран. Подключается внутри Vercel, ключи копировать не нужно.

1. В проекте откройте вкладку **Storage**.
2. Нажмите **Create Database** и выберите **Upstash** (Redis).
3. Выберите бесплатный план **Free**, нажмите **Create** и подключите базу к проекту (**Connect**).
4. Откройте **Deployments**, нажмите **⋯** у последней публикации и выберите **Redeploy**.

## Музыка

Файл `public/audio/music.mp3`. Чтобы заменить музыку, загрузите другой MP3 с тем же именем.

## Лимиты

Бесплатный план Upstash включает 500 000 команд в месяц. Открытый экран расходует примерно 3 600 команд в час.
